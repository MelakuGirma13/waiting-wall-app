## prisma Synchronize changes from supabase (migration)
1. must start from PrismaOrm schema.prisma
2. mkdir -p prisma/migrations/0_init_supabase //Create a migration file //manual folder migration cration // creted once
3. npx prisma migrate diff \
  --from-empty \
  --to-schema-datamodel prisma/schema.prisma \
  --script > prisma/migrations/0_init_supabase/<migration_name>.sql    //Synchronize the migrations //generate(update) migration file with given name <migration_name>
    3.1 => if its first time creation migratin file use below command, file name must be migraton.sql
            npx prisma migrate diff \
            --from-empty \
            --to-schema-datamodel prisma/schema.prisma \
            --script > prisma/migrations/0_init_supabase/migration.sql
4. npx prisma migrate dev --name <name> //updates(sync) supabase and prisma 

## pull from supabase (NB: you will loose migration histry if exist)
 1. npx prisma format
 2. npx prisma db pull //Pull existing Supabase schema (optional but recommended)
